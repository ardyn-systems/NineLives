# Bundled examples

Sample data shipped inside NineLives so a fresh install works out of the box.

- `Coherer-sample.hc22000` — a WPA (mode 22000) hash extracted from the public
  *wpa-Induction* capture (ESSID `Coherer`). Pre-loaded in the Captures tab on
  first run.
- `wpa-demo.txt` — a tiny demo wordlist containing the passphrase `Induction`,
  so cracking the sample recovers it immediately.

For **authorized** auditing only. The sample is a well-known public test capture.
